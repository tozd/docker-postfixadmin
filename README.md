## Description

Image provides [Postfix Admin](https://postfixadmin.github.io/postfixadmin/), a web interface to manage
domains, mailboxes, and aliases of a Postfix and Dovecot mail server stored in a database.
When the container runs Postfix Admin is available at `/postfixadmin/` URL.

By default the image uses a SQLite database stored in `/var/lib/postfixadmin` volume.
Configure the image by mounting a volume or extending the image to add `.php` configuration files
to `/etc/postfixadmin/conf.d`, for example:

```php
<?php
$CONF['database_type'] = 'pgsql';
$CONF['database_host'] = 'postgresql';
$CONF['database_user'] = 'postfixadmin';
$CONF['database_password'] = 'password';
$CONF['database_name'] = 'postfixadmin';
$CONF['setup_password'] = '<hash generated by setup.php>';
```

Configuration files have to be readable by the `fcgi-php` user. Available options are documented in
[`config.inc.php`](https://github.com/postfixadmin/postfixadmin/blob/master/config.inc.php).

On every container startup the image creates the database schema if the database is empty, or applies
any pending upgrades of the database schema. The database user needs privileges to create and alter tables.
To create the first admin account, set `setup_password` and open `/postfixadmin/setup.php`.

The image includes an SSH client, so `mailbox_postcreation_script` and similar options can run scripts
on the mail server over SSH.
